# brainfuck playground
This repository is a playground for me to work on various brainfuck compilers, interpreters and whatever else. This is for the sake of study, as I want to get better at writing lower level code, compiler design and programming in general :-).

## haskell
This is a basic brainfuck interpreter written in haskell. Takes in a file as the brainfuck program to run & processes it. Uses set theory to process the lexer & a single state machine for execution. My first time writing Haskell :-).
